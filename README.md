## Overview

DevArt Elements is a modern Joomla 6 native extension for creating reusable content elements that can be displayed anywhere on your website using the included module.

The extension provides an easy way to build interactive and reusable content blocks including FAQs, Tabs, Accordions, Navigation, Pricing Tables, Media Blocks and more while maintaining excellent performance, flexibility and production-ready reliability.

Designed for modern Joomla websites, DevArt Elements follows native Joomla architecture and integrates seamlessly with Joomla 6.
